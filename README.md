# What's the weather

What's the weather is a vanilla Javascript, HTML, and CSS project that leverages the Open Meteo API to get weather temperature, 10-day forecast, and elevation from the city of your choice.

# APIs Used 

 1. [Geocoding](https://open-meteo.com/en/docs/geocoding-api)
 2. [Weather](https://open-meteo.com/en/docs/gfs-api)
 3. [Elevation](https://open-meteo.com/en/docs/elevation-api)

 # How to Run

 1. Git clone https://github.com/JamesJohnson11/whats-the-weather.git or download the zip.
 2. Open cloned repo in VS Code.
 3. Right-click the "index.html" file and select "Open in Integrated browser".
 4. If you'd like to open in browser instead, go to the cloned folder on your system, right-click the index.html file and select the "Open With" option. Then select the Chrome or Safari from that list.
